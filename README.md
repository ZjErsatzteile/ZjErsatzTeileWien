# ZJ Ersatzteile – GitHub Pages

Eine responsive blau-schwarze KFZ-Ersatzteile-Webseite mit WhatsApp-Anfrageformular.

## Dateien

- `index.html` – komplette Website
- `style.css` – Design, Animationen und Responsive Layout
- `script.js` – WhatsApp-Anfrageformular
- `assets/ersatzteile-showcase.png` – große KFZ-Ersatzteile-Showcase-Grafik im Hero-Bereich

## Auf GitHub veröffentlichen

1. Neues GitHub-Repository erstellen, z. B. `zj-ersatzteile`.
2. Alle Dateien aus diesem Ordner hochladen.
3. In GitHub: **Settings → Pages**.
4. Bei **Build and deployment** `Deploy from a branch` auswählen.
5. Branch `main` und Ordner `/ (root)` auswählen.
6. Speichern. Nach dem Deployment ist die Seite über deine GitHub-Pages-Adresse erreichbar.
